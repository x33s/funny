# Chat FAB — 小宠物

## 概述

46px 圆形黑色半透明毛玻璃 FAB，内部白色圆角矩形 + 两圆点眼睛。眼睛跟随鼠标在圆内偏移；鼠标距离 > 260px 变菱形并眨眼；白色矩形独立上下浮动。靠近/远离时弹出轻松可爱文案气泡，每条最少保留 4s。点击图标冒 6~8 颗飘散爱心，切换 active 状态。点击空白处不触发任何特效。

## 何时使用

- 需要右下角/任意位置的对话、客服、助手入口
- 希望悬浮按钮有"注视感"和宠物拟人微交互
- 需要可拖拽、带情绪反馈的轻量组件

## 核心行为

| 行为 | 触发 | 效果 |
|---|---|---|
| 眼睛瞟动 | 鼠标距 ≤ 260px | 朝鼠标方向偏移，最大 2.5px |
| 菱形眨眼 | 鼠标距 > 260px | 圆点眼淡出→菱形眼淡入，`scaleY` 眨眼 |
| 矩形浮动 | 常驻 | 白色矩形 `translateY(-3px)`，圆底不动 |
| 气泡 4 档 | 距离 0–70 / 70–260 / 拖拽 / 点击 | 每档随机文案，锁定 4s |
| 拖拽 | mousedown 位移 > 3px | 位置跟随，夹在视口内 |
| 图标点击 | 位移 ≤ 3px | 切 active + 开心文案 + 6~8 颗飘散爱心 |
| 空白点击 | — | 无任何特效（不冒爱心） |

## 关键参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `SIZE` | 46 | 按钮直径 px |
| `FAR_DIST` | 260 | 变菱形 / 气泡隐藏阈值 |
| `CLOSE_DIST` | 70 | 贴贴档阈值 |
| `HOLD_MS` | 4000 | ★ 单条文案最少展示时长 |
| `FLASH_MS` | 1800 | 点击反馈文案时长 |
| `MAX_OFFSET` | 2.5 | 眼睛最大偏移 px |
| 浮动 | -3px / 3.2s | 白色矩形上下位移 |
| 眨眼 | 3s | 40%→45% 压扁到 0.1 |

## 实现要点

- **气泡 4s 锁定**：`lockUntil = Date.now() + HOLD_MS`，锁定期内鼠标移动不切档、不隐藏；到期由 `tick()` 统一重估。拖拽 `dragOverride` 与点击 `flashUntil` 各自独立接管。
- **爱心纯 CSS**：旋转 45° 正方形 + 两个 `border-radius:50%` 伪元素；`heartFloat` 用 CSS 变量 `--dx/--dy/--rot` 传每颗心的随机漂移，`hue` 微随机。**只在图标点击时从中心成团冒出**，空白点击不做任何响应。
- **只在确认拖拽后切文案**：位移 > 3px 才触发，避免点击瞬间误闪 drag 文案。
- **浮动只加在 `.face`**：不与 `left/top` 定位冲突。

## 注意事项

- `backdrop-filter` 需 `-webkit-` 前缀兜底。
- 气泡靠近顶部（`pos.y < 100`）自动翻转到下方。
- 拖拽用 `mousedown → mousemove/mouseup`，位移 ≤ 3px 视为点击。
- 所有爱心 DOM 用 `setTimeout` 清理，不累积。
- 未监听页面空白点击，避免干扰宿主页面其他交互。
